Scadenze, promemoria ed eventi, sempre in ordine

GADA9 Agenda è un'agenda per Windows che salva le tue scadenze nel tuo Google Calendar e ti avvisa a schermo all'ora giusta, anche ad agenda chiusa.

Scadenze e tipi

Crea scadenze con tipi, colori e promemoria; raggruppa più voci in un'unica scadenza e spuntale una alla volta.

Google Calendar

Le scadenze vengono scritte nel calendario che scegli tu, così le ritrovi anche sul telefono.

Avvisi di Windows

Promemoria a schermo programmati in Windows, anche quando l'agenda è chiusa.

Allegati

Immagini e documenti nelle note, in qualità originale, salvati nel tuo Google Drive.

Come usa i dati di Google

GADA9 Agenda funziona interamente sul tuo computer e comunica solo con il tuo account Google. Usa:

  • Google Calendar: per leggere, creare e modificare le scadenze nel calendario dell'agenda che scegli nelle Impostazioni.
  • Google Drive (solo file creati dall'app): per salvare e riaprire gli allegati delle note. L'app non vede gli altri file del tuo Drive.

Nessun dato viene inviato a server di terzi, venduto o usato per pubblicità. I dettagli sono nell'informativa sulla privacy.

In English

GADA9 Agenda is a Windows desktop planner that stores deadlines and reminders in the user's own Google Calendar and shows Windows notifications at the right time. It uses the Google Calendar API to read and write events in the calendar chosen by the user, and the Google Drive API (drive.file, files created by the app only) to store note attachments. Data never leaves the user's computer and Google account. See the privacy policy.
